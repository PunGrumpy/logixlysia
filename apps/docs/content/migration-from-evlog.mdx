---
title: Migrating from evlog
description: Map evlog wide events to Elogs request context and access logs
---

## Plugin setup

**evlog**

```ts
import { evlog } from 'evlog/elysia'

new Elysia().use(evlog({ drain: myDrain }))
```

**Elogs**

```ts
import { createElogs } from 'createElogs'

new Elysia().use(createElogs({ preset: 'prod' }))
```

## Context accumulation

| evlog | Elogs |
| ----- | ---------- |
| `log.set({ userId: 'x' })` | `store.logger.mergeContext(request, { userId: 'x' })` |
| `log.set({ cart: { total: 99 } })` | `store.logger.mergeContext(request, { cart: { total: 99 } })` |
| `useLogger()` | `store.logger` in handlers |

## Emitting the request log

evlog:

```ts
log.emit({ status: 200 })
```

Elogs emits the access log automatically in `onAfterHandle`. Use a custom log only when you need to skip the default line:

```ts
store.logger.info(request, 'handled manually')
```

## AI metrics

**evlog** — automatic via `evlog/ai`.

**Elogs**

```ts
import { mergeAIMetrics } from 'createElogs/ai'

mergeAIMetrics(store.logger, request, {
  model: 'claude-sonnet',
  inputTokens: 100,
  outputTokens: 50,
  totalTokens: 150
})
```

## Tracing

Use `injectTraceContext` from `createElogs/otel` in the `request` hook (see [OpenTelemetry](/docs/integrations/otel)).

## Drains vs transports

evlog **drains** map to Elogs **transports**:

```ts
createElogs({
  config: {
    transports: [
      {
        log: (level, message, meta) => {
          myDrain.write({ level, message, ...meta })
        }
      }
    ],
    useTransportsOnly: true
  }
})
```
