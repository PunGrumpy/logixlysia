### `AutoTranslateConfig`

自动翻译配置 —— 在单点 onError 钩子里跑一组 translator,
翻译后的 error 决定日志级别和记录内容,但**不**改变错误传播。

**关键不变量**:翻译只影响日志输出,不劫持错误处理流程。错误继续
以原 error 形态传播,用户的 ``.error(MyClass, fn)`` / Elysia 默认
``application/problem+json`` 响应都不受影响。

| Field | Type | Optional | Description |
| --- | --- | --- | --- |
| `custom` | `ErrorTranslator[]` | ✓ | 用户自定义 translator(在内置之后执行,优先匹配) |
| `db` | `"drizzle"` |  | 启用的 DB 类型,选择内置 translator 集合 |

### `Logger`

Logger 实例,可通过 ``store.logger`` 访问

9 个方法:
- debug / info / warn / error: 便利级别快捷方法
- log: 显式 level + data 入口
- handleHttpError: 错误处理入口
- getContext / mergeContext: per-request 累积 context
- pino: 底层 Pino Logger

| Field | Type | Optional | Description |
| --- | --- | --- | --- |
| `debug` | `(request: Request, message: string, context: Record&lt;string, unknown&gt;) =&gt; void` |  | 记录 DEBUG 级别日志 |
| `error` | `(request: Request, message: string, context: Record&lt;string, unknown&gt;) =&gt; void` |  | 记录 ERROR 级别日志 |
| `getContext` | `(request: Request) =&gt; Readonly&lt;Record&lt;string, unknown&gt;&gt;` |  | 获取累积的 per-request context |
| `handleHttpError` | `(request: Request, error: unknown, store: StoreData, options: CreateElogsOptions) =&gt; void` |  | 处理 HTTP 错误并输出日志 |
| `info` | `(request: Request, message: string, context: Record&lt;string, unknown&gt;) =&gt; void` |  | 记录 INFO 级别日志 |
| `log` | `(level: LogLevel, request: Request, data: Record&lt;string, unknown&gt;, store: StoreData) =&gt; void` |  | 记录指定级别的日志 |
| `mergeContext` | `(request: Request, partial: Record&lt;string, unknown&gt;) =&gt; void` |  | 合并 per-request context(后续 access log 带上) |

## Classes

### `httpError()` factory

Use the `httpError()` factory from `elogs` to throw RFC 9457-compliant errors. The factory returns
an Elysia 2 `HTTPError` instance with `type` (URI), `status`, and `detail()` correctly populated,
so Elysia automatically serves the response as `application/problem+json`.

```ts
import { httpError } from "@pori15/elogs";

throw httpError(404, "user not found", { userId: 42 });
// → 404 + application/problem+json + elogs 写一条 WARNING 日志
```

> The previous lowercase `HttpError` class has been removed. If you were using it, migrate to
> `httpError()` (or extend Elysia's `HTTPError` directly for more control).
