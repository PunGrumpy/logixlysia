Reads an existing request ID from the incoming request header, or generates a
new one using the configured generator.

Inbound values are validated against ``VALID_REQUEST_ID`` (alphanumeric plus
``.``, ``_``, ``-``, 1-128 chars) before being trusted — request IDs flow into log
lines, response headers, and context trees, so malformed or oversized
values are replaced with a freshly generated one rather than echoed back.

| `transport` | `Transport` |  |

### `tee`

把一条 log 同时发到多个 transport。每个分支都跑,互不影响。
任一分支 reject 不会短路其它分支(用 Promise.allSettled 兜底)。

```ts
function tee(targets: Transport[]) => Transport;
```

**Parameters**

| Name | Type | Description |
| --- | --- | --- |
| `targets` | `Transport[]` |  |

### `translateDrizzleError`

翻译一个错误。如果命中某个 translator,返回 ``httpError(...)``(原 error
信息会被吞掉,只保留 status + message);如果不命中,原样返回(若不是
Error 实例则包成 ``new Error(String(e))``)。

```ts
function translateDrizzleError(error: unknown, custom?: ErrorTranslator[]) => Error;
```

**Parameters**

| Name | Type | Description |
| --- | --- | --- |
| `error` | `unknown` | 任意 unknown(通常是 try/catch 块里的 e) |
| `custom` | `ErrorTranslator[]` | 用户自定义 translator,会先于内置 translators 执行,   命中后直接返回(短链) |
