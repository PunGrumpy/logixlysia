Save your logs to files for persistence and analysis using Logixlysia's file logging system.

## Basic Usage

```ts
logixlysia({
  config: {
    logFilePath: './logs/app.log'
  }
})
```

## Configuration

| Option        | Type     | Description          | Default     |
| ------------- | -------- | -------------------- | ----------- |
| `logFilePath` | `string` | Path to the log file | `undefined` |

## File Format

Each log is one line, with no colors or icons:

```
2025-04-13T15:00:19.225Z INFO GET /api/users 200 123.45ms
2025-04-13T15:00:20.225Z ERROR POST /api/users 500 234.56ms Error creating user
2025-04-13T15:00:21.225Z INFO GET /api/users - 0.17ms Loaded users {"count":3}
```

The fields are, in order, a UTC ISO 8601 timestamp, the level, the method, the path, the status, the duration, the message, and the context as JSON. The message and context are left out when empty. The status is `-` for a line you write with `log.info()` and similar, which belongs to no response. Newlines and control characters are escaped, and `autoRedact` masks the message and context before they are written.

The file line has a fixed layout. `customLogFormat` and `timestamp.translateTime` shape the console only.

## Best Practices

- Use descriptive file names
- Organize logs by type/level
- Consider using date-based directories
- Set appropriate file permissions
- Avoid logging sensitive data
- Regular log review and cleanup

## Examples

### Production

```ts
logFilePath: './logs/production.log'
```

### Development

```ts
logFilePath: './logs/development.log'
```
