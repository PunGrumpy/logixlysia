---
title: File Logging
description: 把日志写入文件以便持久化
---

用 Elogs 的 file sink 把日志写入文件,持久化和分析都用得上。

## 基本用法

```ts
createElogs({
  config: {
    logFilePath: './logs/app.log',
  },
})
```

## 配置项

| 选项 | 类型 | 描述 | 默认 |
| --- | --- | --- | --- |
| `logFilePath` | `string` | 日志文件路径 | `undefined` |
| `logFileMode` | `number` | 文件权限位 (chmod) | `0o600` |
| `logDirMode` | `number` | 目录权限位 (chmod) | `0o700` |
| `logRotation` | `LogRotationConfig` | rotation 策略 | `undefined` |

## 工作机制

file sink:

1. **缓存文件句柄** —— 按路径缓存,重复写入同一文件复用句柄,不必每次 `writeFile`。
2. **批写** —— 通过 `queueMicrotask` 批处理,同一 tick 内的多条日志合并成单次 `writev`。
3. **跨文件 rotation 串行** —— keyed mutex 串行,rotate 文件 A 不会阻塞文件 B 的写入。
4. **文件 `0o600`、目录 `0o700`** —— 默认权限。可通过 `logFileMode` / `logDirMode` 覆盖。

## 文件格式

日志用跟 console 一样的格式(根据 `customLogFormat` token 集合,或内置默认):

```
🦊 2025-04-13 15:00:19.225 INFO  123.45ms GET /api/users 200
🦊 2025-04-13 15:00:20.225 ERROR 234.56ms POST /api/users 500 Error creating user
```

## 示例

### 生产

```ts
createElogs({
  config: {
    logFilePath: './logs/production.log',
    logRotation: {
      maxSize: '100m',
      interval: '1d',
      maxFiles: '30d',
      compress: true,
    },
  },
})
```

### 开发

```ts
createElogs({
  config: {
    logFilePath: './logs/development.log',
  },
})
```

### 自定义文件权限

```ts
createElogs({
  config: {
    logFilePath: '/var/log/myapp/app.log',
    logFileMode: 0o640,
    logDirMode: 0o750,
  },
})
```

### 关闭文件输出

```ts
createElogs({
  config: {
    logFilePath: './logs/app.log', // 配置了
    disableFileLogging: true,      // ...但关闭
  },
})
```

## 最佳实践

- 用有描述性的文件名
- 按类型 / 级别拆分日志(access log、error log 分开)
- 设置合适的文件权限 —— `0o600`/`0o700` 是大多数生产的合理选择
- 避免记录敏感数据 —— 开启 `autoRedact`,让 PII 在到达文件前就替换
- 长时间运行的服务搭配 [Log Rotation](/docs/features/log-rotation) 一起用
