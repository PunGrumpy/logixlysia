---
title: Presets
description: 现成的 dev、prod、json 日志默认值
---

用 `preset` 一行设好环境默认。显式 `config` 字段永远覆盖 preset。

```ts
import { Elysia } from 'elysia'
import { createLogPlugin } from '@pori15/createLogPlugin'

const app = new Elysia().use(
  createLogPlugin({
    preset: 'prod',
    config: {
      service: 'api',
      logFilePath: './logs/app.log',
    },
  })
)
```

## 可用 preset

| Preset | 启动 banner | 美化输出 | context 树 | `autoRedact` | `requestId` |
| --- | --- | --- | --- | --- | --- |
| `dev` | 是(banner) | 是 | 是 | 否 | 否 |
| `prod` | 否 | 否 | 否 | 是 | 是 |
| `json` | 否 | 否 | 否 | 否 | 否 |

`json` 是日志聚合器(Datadog、Loki、Elasticsearch)的最小配置 —— 关掉所有装饰性输出,JSON 是唯一 payload。下游需要解析行分隔 JSON、又不需要人类可读格式时用它。

## 覆盖示例

```ts
createLogPlugin({
  preset: 'prod',
  config: {
    autoRedact: false,
    showStartupMessage: true,
  },
})
```

## 程序化解析

如果想先看解析后的 options 再往下传,用 `resolveOptions`:

```ts
import { resolveOptions } from '@pori15/createLogPlugin'

const options = resolveOptions({ preset: 'dev', config: { service: 'api' } })
// options.config.service === 'api'
// options.config.showStartupMessage === true (来自 dev preset)
```

`resolveOptions` 就是插件内部用的同一个 merge 函数,行为跟直接传给 `createLogPlugin()` 完全一致。

## 自定义 preset

`registerPreset(name, defaults)` 在进程级注册一个 preset,跟内置 `dev` / `prod` / `json` 一样被 `resolveOptions` 查表。适合在 monorepo 里把"staging / edge / canary"等环境的默认值抽到一处,而不是每个项目复制粘贴 12 行 config。

```ts
import { registerPreset } from '@pori15/createLogPlugin'

registerPreset('staging', {
  pino: { prettyPrint: true },
  showContextTree: true,
  requestId: true,
  autoRedact: true,
  useColors: true,
})

const app = new Elysia().use(createLogPlugin({ preset: 'staging' }))
```

**规则**

- 重复注册同名 preset 抛 `Error("createLogPlugin: preset \"<name>\" already registered")` —— 防止 typo 静默覆盖。
- `name` 必须是非空字符串。
- 用户 preset 的 schema 跟 `LogixlysiaConfig` 完全一致,**不**做轻量校验(`resolveOptions` 阶段统一管 `logRotation` 之类)。
- 注册时机:模块加载时一次性注册,放**自己项目的初始化入口**(比如 `src/logging.ts`),**不要**在请求处理函数里注册 —— 重复抛错会让第一个请求 500。

**调试用 API**

```ts
import { listPresets, getPresetDefaults } from '@pori15/createLogPlugin'

console.log(listPresets())
// ['dev', 'prod', 'json', 'staging']

console.log(getPresetDefaults('staging'))
// { pino: { prettyPrint: true }, showContextTree: true, ... }
```

**测试重置**

单测之间清掉注册表用 `__resetPresetRegistry()`(注意:会**连同**内置 `dev` / `prod` / `json` 一起清掉,生产代码绝不能调):

```ts
import { __resetPresetRegistry } from '@pori15/createLogPlugin'

afterEach(() => {
  __resetPresetRegistry()
})
```

**类型上**(TypeScript):`preset` 字段的提示仍是 `'dev' | 'prod' | 'json'`,但运行时接受任意字符串。IDE 自动补全给内置,用户 preset 用 `as` 断言或 `satisfies` 收口:

```ts
createLogPlugin({ preset: 'staging' as 'dev' | 'prod' | 'json' | 'staging' })
```
