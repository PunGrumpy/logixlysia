---
title: Log Levels
description: 控制日志详细程度
---

用 Logixlysia 的级别系统控制日志输出的详细程度。级别是大小写不敏感的字符串:`DEBUG`、`INFO`、`WARNING`、`ERROR`。

## 可用级别

```
DEBUG > INFO > WARNING > ERROR
```

Logixlysia 用的是**白名单过滤**,不是层级。`logFilter.level: ['ERROR']` 只输出 `ERROR`;`['ERROR', 'WARNING']` 输出这两个。数组里的顺序无关紧要。

## 配置

### 单个级别

```ts
createLogPlugin({
  config: {
    logFilter: { level: 'ERROR' },
  },
})
```

### 多个级别

```ts
createLogPlugin({
  config: {
    logFilter: { level: ['INFO', 'ERROR'] },
  },
})
```

### 根级简写

`logLevel` 在 options 根级,等价于 `config.logFilter.level`:

```ts
createLogPlugin({ logLevel: ['ERROR', 'WARNING'] })
```

两种形式都会合并:同时设置时 `logLevel` 胜出(根级简写优先)。

### 按环境配置

```ts
createLogPlugin({
  config: {
    logFilter: {
      level: process.env.NODE_ENV === 'production'
        ? ['ERROR', 'WARNING']
        : ['DEBUG', 'INFO', 'WARNING', 'ERROR'],
    },
  },
})
```

## 状态派生的级别

除了 `logFilter.level`,每条 access log 还会按响应状态码派生出级别:

| 状态码范围 | 级别 |
| --- | --- |
| `200`–`399` | `INFO` |
| `400`–`499` | `WARNING` |
| `500`–`599` | `ERROR` |

派生出来的级别也会被 `logFilter.level`(或 `logLevel`)过滤 —— `level: ['ERROR']` 时 404 不会产生输出。

## Pino 自己的级别

Pino 也有自己的级别系统(`fatal`、`error`、`warn`、`info`、`debug`、`trace`)。`config.pino.level` 控制 Pino 的门槛,跟 `logFilter.level` 相互独立:

```ts
createLogPlugin({
  config: {
    pino: { level: 'debug' },
  },
})
```

Pino 在首次访问时按需构造。把 `config.pino` 设为真值可以让错误的 Pino 选项在启动时 fail-fast。

## 最佳实践

- **开发:** `['DEBUG', 'INFO', 'WARNING', 'ERROR']` —— 全部四个
- **Staging:** `['INFO', 'WARNING', 'ERROR']` —— 去掉 DEBUG
- **生产:** `['ERROR', 'WARNING']` —— 去掉 INFO 和 DEBUG
- **告警:** `['ERROR']` —— 只在错误时告警
