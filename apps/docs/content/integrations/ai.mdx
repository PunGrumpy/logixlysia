title: AI SDK metrics
description: 把 LLM 用量指标挂到请求日志
---

从 `@pori15/logixlysia/ai` 子路径导入(无必需 peer 依赖):

```ts
import { logixlysia } from '@pori15/logixlysia'
import { mergeAIMetrics } from '@pori15/logixlysia/ai'

const plugin = logixlysia()

const app = new Elysia()
  .use(plugin)
  .post('/chat', async ({ request, store }) => {
    // 在 AI SDK 调用之后:
    mergeAIMetrics(store.logger, request, {
      model: 'claude-sonnet',
      provider: 'anthropic',
      inputTokens: 1200,
      outputTokens: 400,
      totalTokens: 1600,
      msToFinish: 2300,
    })

    return { ok: true }
  })
```

最终的 access log `context.ai` 对象沿用 evlog wide event 的 `ai` 字段,方便两边对照迁移。

## API

```ts
function mergeAIMetrics(
  logger: Pick<Logger, 'mergeContext'>,
  request: Request,
  metrics: AIMetrics
): void

interface AIMetrics {
  model: string
  provider: string
  inputTokens: number
  outputTokens: number
  totalTokens: number
  msToFinish: number
  // 可选费用估算(美元)
  costUsd?: number
  // 可选 cache 命中/未命中分布
  cacheReadTokens?: number
  cacheWriteTokens?: number
}
```

`mergeAIMetrics` 调用 `logger.mergeContext(request, { ai: { ...metrics } })`。指标是合并(不是替换),后续用不同 model 调用只覆盖 `model` key。

## 带费用追踪的示例

```ts
app.post('/chat', async ({ request, store }) => {
  const start = performance.now()
  const response = await anthropic.messages.create({ /* ... */ })

  mergeAIMetrics(store.logger, request, {
    model: response.model,
    provider: 'anthropic',
    inputTokens: response.usage.input_tokens,
    outputTokens: response.usage.output_tokens,
    totalTokens:
      response.usage.input_tokens + response.usage.output_tokens,
    msToFinish: performance.now() - start,
    costUsd: estimateCost(response.model, response.usage),
  })

  return { ok: true }
})
```

## 带 cache 分布(Anthropic prompt caching)

```ts
mergeAIMetrics(store.logger, request, {
  model: 'claude-sonnet',
  provider: 'anthropic',
  inputTokens: response.usage.input_tokens,
  outputTokens: response.usage.output_tokens,
  totalTokens: response.usage.input_tokens + response.usage.output_tokens,
  cacheReadTokens: response.usage.cache_read_input_tokens ?? 0,
  cacheWriteTokens: response.usage.cache_creation_input_tokens ?? 0,
  msToFinish: 2300,
})
```

access log 里会显示:

```
context: {
  ai: {
    model: 'claude-sonnet',
    provider: 'anthropic',
    inputTokens: 1200,
    outputTokens: 400,
    totalTokens: 1600,
    msToFinish: 2300,
    cacheReadTokens: 900,
    cacheWriteTokens: 200,
  }
}
```

## 易于聚合

`ai` 字段结构稳定,可以在任何日志后端聚合:

```
SELECT
  context->'ai'->>'model' AS model,
  AVG((context->'ai'->>'totalTokens')::int) AS avg_tokens,
  AVG((context->'ai'->>'msToFinish')::float) AS avg_latency_ms
FROM logs
WHERE context->'ai' IS NOT NULL
GROUP BY model
```
