Complete reference for all Logixlysia configuration options. All fields are passed under the `config` key of `logixlysia({...})`, with one shorthand (`logLevel`) at the root.

```ts
logixlysia({
  preset: 'prod',  // optional: 'dev' | 'prod' | 'json'
  config: {
    // ... configuration options (override preset)
  },
})
```

See [Presets](/docs/features/presets) for defaults per environment.

## Preset

### `preset`

One-line environment defaults. Explicit `config` fields always win.

- **Type:** `'dev' | 'prod' | 'json'`
- **Default:** `undefined` (no preset)

```ts
logixlysia({ preset: 'prod' })
```

## Startup

### `showStartupMessage`

Whether to display the startup message when the server starts.

- **Type:** `boolean`
- **Default:** `true`

### `startupMessageFormat`

Format of the startup message.

- **Type:** `'simple' | 'banner'`
- **Default:** `'banner'`

The startup message is emitted from the `.start()` hook, reading `instance.server` (Elysia 2) or the `PORT` / `HOST` env vars as a fallback.

## Display

### `useColors`

Enable colored output in console logs.

- **Type:** `boolean`
- **Default:** `true` (auto-disabled when `!process.stdout.isTTY`)

### `ip`

Include client IP address in logs.

- **Type:** `boolean`
- **Default:** `false`

**How IP is resolved:** the client IP is read from HTTP headers in this order:

1. `x-forwarded-for` — first (leftmost) IP in the comma-separated list
2. `x-real-ip` — fallback when `x-forwarded-for` is not present

### `autoRedact`

Automatically redacts sensitive data from log messages, context objects, errors, and request headers. Redaction runs in two ways:

1. **By key/header name** — a built-in, case-insensitive denylist (`authorization`, `cookie`, `x-api-key`, `password`, `secret`, `token`, `session`, and more) wholly redacts the value of any matching object key or request header.
2. **By value pattern** — emails, IP addresses, Luhn-valid payment card numbers, and JWTs are redacted wherever they appear in strings.

- **Type:** `boolean`
- **Default:** `false`

### `redactKeys`

Additional key/header names to redact when `autoRedact` is enabled, extending the built-in denylist.

- **Type:** `string[]`
- **Default:** `undefined`

```ts
autoRedact: true,
redactKeys: ['x-internal-token', 'customerSsn']
```

### `logErrorPayload`

Log the offending payload (`found` / `errors`) from validation errors. Off by default.

- **Type:** `boolean`
- **Default:** `false`

### `logQueryParams`

Include query parameters in the logged URL path.

- **Type:** `boolean`
- **Default:** `false`

## Formatting

### `customLogFormat`

Custom log message format using placeholders.

- **Type:** `string`
- **Default:** `undefined` (built-in default includes `{now}`, `{service}`, `{icon}`, `{method}`, `{pathname}`, `{status}`, `{duration}`, `{message}`, `{speed}`)

```ts
customLogFormat: '{now} {level} {duration}ms {method} {pathname} {status}'
```

Available placeholders:

| Placeholder | Description |
| ----------- | ----------- |
| `{now}` | Current timestamp |
| `{epoch}` | Unix timestamp (seconds) |
| `{level}` | Log level |
| `{duration}` | Request duration, formatted (e.g. `12ms`, `1.5s`) |
| `{method}` | HTTP method |
| `{pathname}` | Request path (alias: `{path}`) |
| `{query}` | Raw query string |
| `{status}` | Response status code |
| `{statusText}` | HTTP status text (e.g. `Not Found` for 404) |
| `{message}` | Custom message |
| `{icon}` | Logixlysia fox `🦊` (level-colored chip when colors + TTY) |
| `{speed}` | Slow-request badge when duration ≥ `verySlowThreshold` |
| `{service}` | Service label from `config.service` |
| `{ip}` | Client IP (from `x-forwarded-for` or `x-real-ip`) |
| `{context}` | Context JSON on main line when tree is off / empty |
| `{requestId}` | `X-Request-Id` value (empty if not enabled) |

### `service`

Service name used by the `{service}` placeholder.

- **Type:** `string`
- **Default:** `undefined`

### `slowThreshold`

Duration threshold (ms) for **green** duration text when colors are enabled. Between this value and `verySlowThreshold`, duration is **yellow**.

- **Type:** `number`
- **Default:** `500`

### `verySlowThreshold`

Duration threshold (ms) at or above which duration is **red** and the `{speed}` token adds `⚡ slow`.

- **Type:** `number`
- **Default:** `1000`

### `showContextTree`

When `true`, structured `context` is printed as **tree lines** under the main log line.

- **Type:** `boolean`
- **Default:** `true`

### `contextDepth`

How many levels of nested objects to expand in the context tree.

- **Type:** `number`
- **Default:** `1`

### `timestamp`

Timestamp format.

- **Type:** `string | { format: string }`
- **Default:** `undefined`

```ts
timestamp: 'yyyy-mm-dd HH:MM:ss.SSS'
// or
timestamp: { format: 'yyyy-mm-dd HH:MM:ss' }
```

## Filtering

### `logFilter`

Log level filter. Accepts a single level or an array.

- **Type:** `{ level?: LogLevel | LogLevel[] }`
- **Default:** `{ level: ['DEBUG', 'INFO', 'WARNING', 'ERROR'] }` (all levels)

```ts
logFilter: { level: ['ERROR', 'WARNING'] }
```

### `logLevel` (root shorthand)

Equivalent to `config.logFilter.level`.

- **Type:** `LogLevel[]`
- **Default:** `undefined` (all levels)

```ts
logixlysia({ logLevel: ['ERROR', 'WARNING'] })
```

## Request ID

### `requestId`

- **Type:** `boolean | RequestIdConfig`
- **Default:** `false`

```ts
requestId: true
// or
requestId: {
  header: 'X-Correlation-Id',
  generator: () => crypto.randomUUID(),
}
```

See [Request ID](/docs/features/request-id).

## AsyncLocalStorage

### `useAsyncLocalStorage`

Enable AsyncLocalStorage propagation so `useLogger()` returns the request-scoped logger from any depth in the call stack.

- **Type:** `boolean`
- **Default:** `false`

```ts
useAsyncLocalStorage: true
```

## File logging

### `logFilePath`

Path to the log file. When set, the file sink writes batched output to this path with `0o600` (file) / `0o700` (directory) permissions by default.

- **Type:** `string`
- **Default:** `undefined`

### `logFileMode`

File permission bits used when creating the log file.

- **Type:** `number`
- **Default:** `0o600`

### `logDirMode`

Directory permission bits used when creating the log directory.

- **Type:** `number`
- **Default:** `0o700`

### `logRotation`

Log rotation configuration.

- **Type:** `LogRotationConfig`
- **Default:** `undefined`

```ts
logRotation: {
  maxSize: '10m',
  interval: '1d',
  maxFiles: '7d',
  compress: true,
}
```

| Field | Type | Description |
| --- | --- | --- |
| `maxSize` | `string \| number` | Rotate when file exceeds this size (`'10m'`, `'5k'`, or bytes) |
| `interval` | `string` | Rotate on a time interval (`'1h'`, `'12h'`, `'1d'`) |
| `maxFiles` | `number \| string` | Max files to keep (count) or retention period (`'7d'`, `'30d'`) |
| `compress` | `boolean` | Gzip-compress rotated files |
| `compression` | `'gzip'` | Compression algorithm (default `gzip`) |

Rotation across files is serialized by a keyed mutex, so rotating file A does not block writes to file B.

## Output

### `transports`

Array of custom transport implementations.

- **Type:** `Transport[]`
- **Default:** `[]`

### `useTransportsOnly`

Use only transports; disable console and file logging.

- **Type:** `boolean`
- **Default:** `false`

### `disableInternalLogger`

Disable console logging.

- **Type:** `boolean`
- **Default:** `false`

### `disableFileLogging`

Disable file logging.

- **Type:** `boolean`
- **Default:** `false`

## WebSocket

### `disableWebSocketLogging`

Suppress automatic logs for `app.ws(...)` routes that pass through `plugin.wrapWs(...)`.

- **Type:** `boolean`
- **Default:** `false`

## Pino

### `pino`

Pino logger configuration. Accepts all [Pino options](https://github.com/pinojs/pino/blob/master/docs/api.md#options).

- **Type:** `PinoLoggerOptions & { prettyPrint?: boolean | object }`
- **Default:** `undefined`

```ts
pino: {
  level: 'info',
  prettyPrint: true,
  redact: ['password', 'token'],
  base: { service: 'my-api' },
}
```

Pino is constructed lazily on first access. Set `config.pino` (truthy) to force eager initialization when you want invalid Pino options to fail at startup.

#### `pino.prettyPrint`

```ts
pino: {
  prettyPrint: {
    colorize: true,
    translateTime: 'HH:MM:ss Z',
    ignore: 'pid,hostname',
  },
}
```

| Option | Type | Description |
| --- | --- | --- |
| `colorize` | `boolean` | Enable colors in output |
| `translateTime` | `string \| boolean` | Format timestamps |
| `ignore` | `string` | Comma-separated keys to exclude |
| `singleLine` | `boolean` | Print each log on one line |
| `messageFormat` | `string` | Custom message format |
| `levelFirst` | `boolean` | Show level before timestamp |
| `messageKey` | `string` | Key containing log message |
| `errorKey` | `string` | Key containing error info |

#### `pino.redact`

```ts
pino: {
  redact: {
    paths: ['user.password', 'req.headers.authorization'],
    remove: true,
  },
}
```

#### `pino.base`

```ts
pino: {
  base: {
    service: 'my-api',
    version: '1.0.0',
    environment: process.env.NODE_ENV,
  },
}
```

## Transport throttling

### `transportThrottleMs`

Window (ms) during which repeated transport errors for the same transport are coalesced into a single `console.error` line.

- **Type:** `number`
- **Default:** `5000`

## Error handling

### `error`

Error-handling configuration.

- **Type:** `{ verbose?: boolean }`
- **Default:** `{ verbose: false }`

```ts
error: { verbose: true }
```

When `verbose` is enabled, logixlysia writes a structured warn with the full error context on top of the level-derived log.

## Complete example

```ts
logixlysia({
  preset: 'prod',
  config: {
    showStartupMessage: false,
    startupMessageFormat: 'simple',

    useColors: true,
    ip: true,
    autoRedact: true,
    redactKeys: ['x-internal-token'],
    logQueryParams: false,
    logErrorPayload: false,

    customLogFormat:
      '{now} {level} {method} {pathname} {status} {duration}ms {requestId}',
    service: 'my-api',
    slowThreshold: 500,
    verySlowThreshold: 1000,
    showContextTree: true,
    contextDepth: 1,

    logFilter: { level: ['INFO', 'WARNING', 'ERROR'] },

    requestId: true,

    logFilePath: './logs/production.log',
    logFileMode: 0o600,
    logDirMode: 0o700,
    logRotation: {
      maxSize: '100m',
      interval: '1d',
      maxFiles: '30d',
      compress: true,
    },

    disableInternalLogger: false,
    disableFileLogging: false,
    useTransportsOnly: false,
    transports: [],

    pino: {
      level: 'info',
      prettyPrint: false,
      redact: ['password', 'token', 'apiKey'],
      base: { service: 'my-api', version: '1.0.0' },
    },
  },
})
```
